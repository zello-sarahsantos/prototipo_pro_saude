# Documentos de regressão da IA

Os arquivos em `documentos/` são os pares usados para testar leitura e conferência no protótipo e no serviço Pró-Saúde IA.

| Conjunto | Arquivos |
| --- | --- |
| 1 | Boleto e comprovante de pagamento Uniplan/Uniconsult |
| 2 | Boleto e comprovante MedSenior |
| 3 | Boleto e comprovante Hapvida, com valores médico e odontológico |
| 4 | Relatório de faturamento e comprovante de pagamento |

Envie cada arquivo individualmente para a IA. A correlação entre boleto/fatura e comprovante é feita pelo fluxo de pagamento, nunca juntando os dois em uma única requisição.

Os documentos contêm dados pessoais e financeiros. Este repositório deve permanecer privado, e os arquivos não devem ser reproduzidos, redistribuídos ou enviados a serviços externos sem autorização.
